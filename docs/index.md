# Machine Learning Specialization — Study Companion

Read-along notes, embedded lectures, in-browser code practice, and per-week self-checks for Andrew Ng's **Machine Learning Specialization**.

## How to use this

- Pick a course → week → topic in the left sidebar.
- Watch the embedded lecture, read the transcript-woven notes, then run the practice cell right on the page.
- Use **prev/next** to move lecture-to-lecture across the whole course.

## Courses

1. **Supervised ML: Regression & Classification**
2. **Advanced Learning Algorithms**
3. **Unsupervised Learning, Recommenders, Reinforcement Learning**
