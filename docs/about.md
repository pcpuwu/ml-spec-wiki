# About & Methodology

An **unofficial personal study companion** to Andrew Ng's Machine Learning Specialization — transparency-first.

!!! warning "Read this first"
    Notes are woven from **machine transcripts** of the lectures and are an AI-written study aid — not an authoritative record. When something matters, trust the lecture and the cited sources.

## Code checks

In-browser exercises run real Python (numpy/sklearn) via Pyodide. A green **Validate** means *your code passed the public + hidden test asserts on this page* — **not** that it would pass Coursera's official grader.

## Supplements

On the neural-network topics, deeper callouts cite Michael Nielsen's *Neural Networks and Deep Learning* and Simon Prince's *Understanding Deep Learning* — used only as enrichment where the lecture is thin.
