    C3 · W1 — K-Means Clustering & Anomaly Detection, in Code¶

    Recommended before this lab

    You'll get the most out of this once you've watched the Course 3 · Week 1 lessons it builds on — the two clustering steps, the cost they minimize, and the Gaussian model behind anomaly detection:

    • K-means Intuition → The K-means Algorithm
    • Optimization Objective (the distortion cost)
    • Gaussian (Normal) Distribution
    • Anomaly Detection Algorithm

    Not strict prerequisites — do the lab in whatever order you like — but this is the theory it turns into code.

    This week has two unsupervised algorithms, and they rhyme: both look at unlabeled data and ask "what does normal look like here?" We'll build both from scratch in NumPy, watch the math from the lessons turn into a few lines of code, and then swap in the library version you'd actually reach for on the job.

    1. K-means — the "assign, then move" loop, hand-rolled, then scikit-learn's KMeans.
    2. Anomaly detection — fit a Gaussian to each feature, multiply the densities, flag the points that land in the tails.

    No labels anywhere. That's the whole point of unsupervised learning.

    0. Setup and some data¶

    For clustering we'll make three loose blobs of points. Because we placed the centers, we can check whether K-means rediscovers them.

    import numpy as np

rng = np.random.default_rng(42)          # fixed seed → reproducible "random" data

centers = np.array([[0.0, 0.0], [5.0, 5.0], [0.0, 6.0]])
X = np.vstack([c + rng.standard_normal((60, 2)) for c in centers])   # 180 points, 2 features
print(X.shape)                           # (180, 2)

    X has m = 180 rows (examples) and n = 2 columns (features) — exactly the x⁽ⁱ⁾ ∈ ℝⁿ setup from the lesson. K-means never sees centers; it only sees X.

    1. K-means from scratch — the two steps¶

    The algorithm is just two operations repeated until nothing changes:

    • Step 1 — assign. Give each point the label of its nearest centroid (c⁽ⁱ⁾ = argmin_k ‖x⁽ⁱ⁾ − μ_k‖²).
    • Step 2 — move. Slide each centroid to the mean of the points assigned to it.

    Step 1 as code¶

    We need, for every point, the distance to every centroid — then pick the smallest. NumPy broadcasting does all m × K distances at once:

    def assign(X, centroids):
    # X[:, None, :] is (m, 1, n); centroids[None, :, :] is (1, K, n) → broadcast to (m, K, n)
    dists = np.linalg.norm(X[:, None, :] - centroids[None, :, :], axis=2)   # (m, K) distances
    return dists.argmin(axis=1)          # index of the closest centroid for each point

    The squared norm and the plain norm pick the same nearest centroid, so we can use either; np.linalg.norm is the readable choice here.

    Step 2 as code¶

    Each new centroid is the column-wise average of its members:

    def move(X, labels, K):
    return np.array([X[labels == k].mean(axis=0) for k in range(K)])   # (K, n) new centroids

    If cluster 1 owns examples 1, 5, 6, 10, this returns their mean — literally μ₁ = ¼(x⁽¹⁾ + x⁽⁵⁾ + x⁽⁶⁾ + x⁽¹⁰⁾) from the lesson.

    The loop¶

    Initialize by picking K actual data points as the starting centroids (Ng's random init), then alternate the two steps:

    K = 3
centroids = X[rng.choice(len(X), K, replace=False)].copy()   # K random points as init

for _ in range(10):
    labels = assign(X, centroids)        # Step 1
    centroids = move(X, labels, K)       # Step 2

print(np.round(centroids, 1))            # ≈ the [0,0], [5,5], [0,6] we started from

    Ten passes is plenty here — K-means usually converges in a handful of iterations, when no point changes label and the centroids stop moving.

    2. The distortion cost — and watching it fall¶

    K-means isn't wandering randomly; it's minimizing the distortion from the optimization lesson — the average squared distance from each point to its centroid:

    \[J = \frac{1}{m}\sum_{i=1}^{m}\big\|x^{(i)} - \mu_{c^{(i)}}\big\|^2.\]
    def distortion(X, labels, centroids):
    return np.mean(np.sum((X - centroids[labels])**2, axis=1))   # mean squared dist to own centroid

    centroids[labels] is a slick move: it builds an (m, n) array where row i is the centroid assigned to point i. Now re-run the loop and print J each iteration:

    centroids = X[rng.choice(len(X), K, replace=False)].copy()
for step in range(10):
    labels = assign(X, centroids)
    centroids = move(X, labels, K)
    print(step, round(distortion(X, labels, centroids), 3))   # monotonically DOWN

    The number goes down every step and then flattens. That's the guarantee from the lesson: each step provably reduces (never increases) J — Step 1 can only lower it by moving points to closer centroids, Step 2 can only lower it by re-centering. If you ever see J rise, you have a bug.

    Why this matters later: this is the same "define a cost, then relentlessly drive it down" pattern as supervised learning — K-means just uses its two-step update instead of gradient descent. Same skeleton, different engine.

    3. How many clusters? The elbow method¶

    K-means needs K up front, and often there's no single right answer. One diagnostic (Géron's elbow, which Ng mentions but rarely relies on): run K-means for a range of K, plot the distortion, and look for the bend where extra clusters stop buying you much.

    def kmeans_distortion(X, K, iters=10):
    centroids = X[rng.choice(len(X), K, replace=False)].copy()
    for _ in range(iters):
        labels = assign(X, centroids)
        centroids = move(X, labels, K)
    return distortion(X, labels, centroids)

for K in range(1, 8):
    print(K, round(kmeans_distortion(X, K), 2))   # drops fast to K=3, then only slowly

    The distortion falls steeply up to K = 3 (our true number of blobs) and then only crawls lower — that flattening is the "elbow." Note what does not work: picking K to minimize distortion just keeps climbing to the largest K, since more centroids always fit tighter.

    4. The library way — scikit-learn¶

    In practice you don't hand-roll any of this. scikit-learn's KMeans does the loop for you, runs it several times from different starts, and keeps the best:

    from sklearn.cluster import KMeans

km = KMeans(n_clusters=3, n_init=10, random_state=42)
labels = km.fit_predict(X)
print(km.cluster_centers_.round(1))      # same three centers you found by hand
print(km.inertia_)                       # the cost — see the note below

    Two details worth knowing:

    • inertia_ is the distortion — but summed, not averaged. scikit-learn reports Σ‖x⁽ⁱ⁾ − μ_c⁽ⁱ⁾‖² (Géron's "inertia"), i.e. our distortion(...) × m. Same quantity, no 1/m. Multiply our value by len(X) and they match.
    • n_init=10 fixes the biggest weakness of the from-scratch version. A single unlucky random init can settle into a bad local optimum. Running 10 inits and keeping the lowest-inertia result (the default uses the smarter k-means++ seeding, which spreads the initial centroids apart) makes that failure rare.

    Predict the cluster for new points with km.predict([[5, 5]]), and read the final centroids off km.cluster_centers_.

    5. Anomaly detection from scratch — a Gaussian per feature¶

    Second algorithm, same unsupervised spirit. We model what normal looks like with a Gaussian on each feature, multiply the per-feature densities into one probability p(x), and flag anything whose p(x) is tiny.

    Fresh dataset: think server-monitoring, two features (say throughput and latency), mostly normal with a few genuine outliers bolted on.

    X_normal = rng.standard_normal((300, 2)) * [2.0, 1.0] + [10.0, 5.0]   # the "healthy" cloud
X_anom   = np.array([[20.0, 12.0], [0.0, 12.0], [18.0, -1.0]])        # 3 planted anomalies
Xa = np.vstack([X_normal, X_anom])

    Fit μ and σ² per feature¶

    Straight from the Gaussian lesson: μⱼ is the average of feature j, σ²ⱼ its average squared deviation. In NumPy that's one call each — and np.var divides by m by default, which is exactly Ng's maximum-likelihood estimate (not the m − 1 version):

    mu  = X_normal.mean(axis=0)              # per-feature mean  μ_j   → shape (n,)
var = X_normal.var(axis=0)               # per-feature var   σ²_j  (ddof=0 → divides by m)
print(mu.round(2), var.round(2))         # ≈ [10, 5] and ≈ [4, 1]

    We fit on X_normal only — the model's job is to learn "normal," so we don't let the anomalies pollute the parameters.

    The density product p(x)¶

    The Gaussian formula and the product-over-features from the lesson, verbatim in code:

    \[p(\vec{x}) = \prod_{j=1}^{n} \frac{1}{\sqrt{2\pi}\,\sigma_j}\, e^{-\frac{(x_j-\mu_j)^2}{2\sigma_j^2}}.\]
    def gaussian_p(X, mu, var):
    coef = 1.0 / np.sqrt(2 * np.pi * var)          # the 1/(√(2π)σ) factor, per feature
    exponent = np.exp(-(X - mu)**2 / (2 * var))     # the bell-curve drop-off, per feature
    return np.prod(coef * exponent, axis=1)         # multiply features → one p(x) per row

    Multiplying is what makes a point anomalous if it's unusual on any feature — an extreme value in even one column tanks the whole product.

    Threshold with ε¶

    Flag a point as an anomaly when p(x) < ε. Pick ε just below the least-likely normal point so the healthy cloud stays in but the outliers fall out:

    p = gaussian_p(Xa, mu, var)
epsilon = p[:300].min() * 0.5            # a hair under the most borderline normal point
flagged = p < epsilon

print("anomalies found at rows:", np.where(flagged)[0])   # → 300, 301, 302: the planted ones
print("false alarms in normal set:", flagged[:300].sum()) # → 0

    The three flagged rows are exactly the ones we planted, with no false alarms in the healthy cloud. In a real system you'd tune ε on a small labeled validation set (that's the developing and evaluating lesson) rather than eyeballing it.

    6. The library way — reuse SciPy's Gaussian¶

    You don't need a library to run this — the from-scratch version is already three lines — but you also shouldn't re-type the bell-curve formula every time. SciPy's norm.pdf is the same p(xⱼ; μⱼ, σ²ⱼ), so the whole density is one .prod:

    from scipy.stats import norm

p_scipy = norm.pdf(Xa, loc=mu, scale=np.sqrt(var)).prod(axis=1)   # note: scale is σ, not σ²
print(np.allclose(p_scipy, gaussian_p(Xa, mu, var)))              # True — identical numbers

    Watch the one gotcha: norm.pdf wants the standard deviation σ (scale=np.sqrt(var)), not the variance. Beyond this per-feature model, scikit-learn ships heavier anomaly detectors (IsolationForest, EllipticEnvelope) for when features interact — but the independent- Gaussian model here is the one Ng teaches, and it's a genuinely strong baseline.

    7. Your turn¶

    These aren't new exercises — each is a small tweak to the code you already ran above, meant to build intuition by poking at it. Try each yourself first; the solution is one click away if you get stuck. Do at least the first two.

    1. Confirm scratch and scikit-learn agree on the cost. km.inertia_ is the summed distortion; your distortion(...) is the mean. Multiply yours by len(X) and compare.

    Solution 
    my_labels = assign(X, km.cluster_centers_)
my_sum = distortion(X, my_labels, km.cluster_centers_) * len(X)
print("scratch (summed):", round(my_sum, 2))
print("sklearn inertia_:", round(km.inertia_, 2))   # essentially equal

    2. Feel a bad random init. Force a single, unlucky start (n_init=1) with a couple of different seeds and print inertia_ — some seeds land in a worse local optimum than others.

    Solution 
    for seed in (0, 1, 2, 3):
    km_bad = KMeans(n_clusters=3, init="random", n_init=1, random_state=seed).fit(X)
    print(seed, round(km_bad.inertia_, 1))   # values vary — that's why n_init > 1 matters

    3. Tighten and loosen ε. Halve epsilon, then double it, and count how many points get flagged each time — the classic precision/recall knob of anomaly detection.

    Solution 
    for factor in (0.25, 0.5, 2.0, 5.0):
    eps = p[:300].min() * factor
    print(f"factor {factor}: {(p < eps).sum()} flagged")   # bigger ε → more (incl. false) alarms

    4. Break the independence assumption. Add a third feature that's just feature0 + feature1 (perfectly correlated) and re-fit — the per-feature model still runs, it just can't "see" the correlation. Confirm the planted anomalies are still caught.

    Solution 
    Xa3 = np.c_[Xa, Xa[:, 0] + Xa[:, 1]]        # add a redundant, correlated 3rd feature
mu3, var3 = X_normal.mean(0), X_normal.var(0)
mu3 = np.r_[mu3, (X_normal[:,0]+X_normal[:,1]).mean()]
var3 = np.r_[var3, (X_normal[:,0]+X_normal[:,1]).var()]
p3 = gaussian_p(Xa3, mu3, var3)
print(np.where(p3 < p3[:300].min() * 0.5)[0])   # 300,301,302 still flagged
